# Dania Companion (Streamlit)

A small Streamlit chat app with session history and a companion-style system prompt.

## Requirements

- Python 3.10+
- A DeepSeek API key in the environment variable `DEEPSEEK_API_KEY`

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run .\Second\Dania_partner.py
```

## Notes

- Session history is stored under `sessions/` (gitignored by default).
